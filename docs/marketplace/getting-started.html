1. Install Claude/Codex Sub Autocomplete in a supported version of IntelliJ IDEA, PyCharm, or Android Studio, and restart your IDE if prompted. Keep the bundled Terminal plugin enabled.
  2. Install and authenticate either the Claude Code CLI or Codex CLI with your subscription. API-key authentication is not supported.
  3. Open Settings → Tools → Claude/Codex Sub Autocomplete.
  4. Choose your provider and model, then run Connection Tests and Diagnostics.
  5. On a fresh installation of 0.6.4 or newer, type in an editor to get automatic suggestions. Press Tab to accept a suggestion or Esc to dismiss it. You can also request a completion with Alt+\.
  6. In your IDE's terminal, type a request such as # list the largest files and press Tab. Review the generated command, edit it if needed, and press Enter yourself to execute it.

Existing automatic, hotkey-only, and disabled preferences are preserved. To request suggestions only with the shortcut, set Automatic typing completions → Off — hotkey only.

Automatic requests use your subscription allowance. Recent-edit, open-tab, and cross-file context are off by default. Generated terminal commands are inserted for review and are never executed automatically.

Version 0.6.4 supports IntelliJ IDEA and PyCharm 2025.3 or newer, and Android Studio Quail 4 (2026.1.4). See the compatibility record for verified builds and coverage limits.
